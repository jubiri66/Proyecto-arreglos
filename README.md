# Sistema de calificaciones con arreglos

**Estudiante:** Jubiri de la nuez S

## Descripción y objetivo
Proyecto individual del Capítulo IX de Introducción a la Programación. Su objetivo es utilizar una lista de Python como vector para almacenar, consultar, modificar y procesar las notas de cinco estudiantes.

## Lenguaje y requisitos
Python 3. No requiere bibliotecas externas.

## Funcionalidades
- Mostrar cinco notas y su estado.
- Consultar una nota mediante su índice.
- Calcular promedio, máximo y mínimo.
- Contar aprobados y reprobados mediante `for` e `if`.
- Modificar una nota por índice y recalcular resultados.
- Validar índices y notas enteras entre 0 y 100.

El criterio educativo de aprobación es 70; no representa necesariamente una política institucional. Los cambios se conservan durante la ejecución, no se guardan al cerrar.

## Ejecución
1. Instalar Python 3.
2. Descargar el repositorio y abrir una terminal en su carpeta.
3. Ejecutar:
   ```bash
   python main.py
   ```
   En Windows también puede utilizarse `py main.py`; en Linux/macOS, `python3 main.py`.
4. Introducir el índice `1` y la nueva nota `80` para reproducir la prueba del documento.

Resultado inicial: promedio 75.20, tres aprobados y dos reprobados.
Resultado después del cambio: promedio 77.80, cuatro aprobados y un reprobado.
